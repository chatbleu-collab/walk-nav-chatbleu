# 걷기 내비

코스를 그려 거리를 재고, 걷는 동안 음성으로 거리·시간·걸음수를 안내받는 PWA 웹앱입니다.

---

## 개인정보에 대해

- **API 키가 없습니다.** OpenStreetMap을 쓰기 때문에 발급받을 키도, 유출될 키도 없습니다.
- **서버가 없습니다.** 위치·경로·걸음수·기록은 전부 폰 안(IndexedDB)에만 저장됩니다. 어디로도 전송되지 않으며 만든 사람도 볼 수 없습니다.
- 외부로 나가는 통신은 **지도 이미지를 받아오는 것 하나뿐**입니다. 이때도 "이 지역 지도를 보여달라"는 요청만 갈 뿐, 누구인지는 전달되지 않습니다.
- **GPX 파일도 폰 안에서만 처리됩니다.** 불러오기·내보내기 모두 브라우저 안에서 끝나며 업로드되지 않습니다.
- 기록을 지우려면 앱에서 삭제하거나, 브라우저 설정에서 이 사이트 데이터를 삭제하면 됩니다.

## GitHub에 올려서 쓰는 법

### 1단계 — 저장소 만들기

1. github.com에 로그인
2. 오른쪽 위 **`+`** → **New repository**
3. Repository name에 `walk-nav` 입력
4. **Public** 선택 (Private은 GitHub Pages가 유료입니다)
5. **Create repository** 클릭

### 2단계 — 파일 올리기

1. 만들어진 저장소 화면에서 **uploading an existing file** 링크 클릭
2. `walk-nav` 폴더를 **연 다음, 그 안의 내용물**을 드래그해서 올립니다
   - ⚠️ `walk-nav` 폴더 자체를 올리면 경로가 한 단계 어긋납니다. **폴더 안쪽**을 올려야 합니다.
   - 올라가야 할 것: `index.html`, `app.css`, `app.js`, `sw.js`, `manifest.json`, `icons` 폴더
3. 아래 **Commit changes** 버튼 클릭

### 3단계 — Pages 켜기

1. 저장소 상단 **Settings** 탭
2. 왼쪽 메뉴에서 **Pages**
3. Source를 **Deploy from a branch**로 두고, Branch를 **main** / **/ (root)** 선택 후 **Save**
4. 1~2분 기다리면 페이지 위쪽에 주소가 나옵니다:
   `https://내아이디.github.io/walk-nav/`

### 4단계 — 폰에 설치

주소를 폰 브라우저로 열고:

- **안드로이드 (크롬)** — 우측 상단 ⋮ → **홈 화면에 추가**
- **아이폰 (사파리)** — 하단 공유 버튼 → **홈 화면에 추가**
  - ⚠️ 아이폰은 반드시 **사파리**로 열어야 합니다. 크롬에서는 설치가 안 됩니다.

설치한 아이콘으로 실행하면 주소창 없이 앱처럼 열립니다.

## 쓰는 법

### 코스 만들기
1. **코스** 탭에서 `◎` 버튼으로 내 위치를 찾습니다
2. 지도를 탭해 걸을 지점을 순서대로 찍습니다 → 거리가 자동 계산됩니다
3. 이름을 넣고 **저장**

`↶` 마지막 점 취소 · `✕` 전체 지우기

### GPX 파일 불러오기

**코스** 탭의 **GPX 불러오기** 버튼 → 폰에 저장된 `.gpx` 파일 선택 → 지도에 바로 그려집니다.
이름을 확인하고 **저장**을 누르면 내 코스 목록에 들어갑니다.

파일은 **폰 밖으로 나가지 않습니다.** 브라우저 안에서 읽고 끝입니다.

**어디서 GPX를 구하나**
- **두루누비** (`durunubi.kr`) — 한국관광공사 운영, 전국 걷기길·자전거길 공식 GPX
- 트랭글, 램블러, Strava, Garmin Connect — 내보내기 / 내려받기 메뉴
- 산림청 숲길, 각 지자체 둘레길 안내 페이지

**아이폰에서 파일이 안 보일 때**
파일 앱에서 GPX가 회색으로 비활성화되지 않도록, 앱이 일부러 파일 종류 제한을 걸지 않았습니다. 그래서 사진 등 **모든 파일이 다 보입니다.** 목록에서 `.gpx` 파일을 직접 찾아 고르세요. 잘못 고르면 앱이 알려줍니다.

카톡·메일로 받은 GPX는 먼저 **파일 앱에 저장**한 뒤 불러오세요.

**점이 많은 파일은 자동으로 정리됩니다**
GPS 기록기로 만든 파일은 1~5m마다 점을 찍어서 3천 개가 넘기도 합니다. 이런 파일은 모양을 유지한 채 점만 줄입니다 (오차 8m 이내). 3천 개가 10~200개로 줄어도 코스 모양과 직각 코너는 그대로 보존됩니다.

반대로 **손으로 찍은 경로(rtept)나 점이 100개 이하인 파일은 하나도 건드리지 않습니다.** 의도적으로 찍은 점이기 때문입니다.

> 덤: GPS 노이즈가 낀 원본 파일은 거리를 부풀려 계산하는 경우가 많습니다. 정리 과정에서 이 오차가 함께 걷힙니다.

### GPX 파일로 내보내기

- **코스** 탭 → **GPX로 저장** : 지금 그린 코스를 파일로
- **기록** 탭 → 각 기록의 **GPX** 버튼 : 실제로 걸은 경로를 파일로

다른 앱으로 옮기거나 PC에 백업할 때 쓰세요.

### 걷기
1. **걷기** 탭에서 코스를 고릅니다 (안 골라도 됩니다)
2. **걷기 시작** → 위치·동작 권한을 **허용**
3. 500m마다 음성으로 안내가 나옵니다
4. 주머니에 넣을 때는 **주머니 모드** → 화면이 까맣게 잠깁니다
   - 해제: 화면을 **1.6초 길게** 누르기

### 코스 이탈 경고가 나오는 방식

- 코스에서 설정한 거리(기본 50m)를 벗어나면 **1~3초 안에** 음성 + 진동으로 즉시 알립니다
- **멈춰 서 있어도 감지됩니다.** 길을 잘못 들어 두리번거릴 때도 경고가 나옵니다
- 계속 이탈 중이면 40초마다 반복하고, **점점 더 멀어지는 중이면 15초마다** 더 자주 알립니다
- 코스로 돌아오면 "코스로 돌아왔습니다"라고 알려줍니다
- 경계선에서 경고가 켜졌다 꺼졌다 하지 않도록, 복귀 판정은 기준의 70% 안쪽으로 들어와야 인정합니다 (기본 35m)

### 기록
**기록** 탭에서 누적 거리·걸음수와 지난 기록을 볼 수 있습니다.

## 꼭 알아두실 점

**화면을 끄면 기록이 멈춥니다.**
브라우저가 개인정보 보호를 위해 백그라운드 위치 추적을 차단하기 때문입니다. 버그가 아니라 정책입니다.
→ **주머니 모드**를 쓰세요. 화면은 켜져 있지만 완전히 까맣고 터치가 잠겨서, 주머니에 넣어도 안전합니다.
→ 배터리는 시간당 10~15% 정도 소모됩니다.

**걸음수는 추정치입니다.**
폰의 가속도 센서로 흔들림을 세는 방식이라 실제와 5~10% 차이가 납니다. 센서를 못 쓰는 경우에는 자동으로 `이동거리 ÷ 보폭`으로 계산합니다. 설정에서 보폭을 조절하면 정확도가 올라갑니다.

**첫 실행은 인터넷이 필요합니다.**
한 번 실행해두면 지도 라이브러리와 지나간 지역의 지도가 캐시에 저장되어, 이후에는 신호가 약한 곳에서도 대부분 동작합니다.

**GPS는 하늘이 트인 곳에서 정확합니다.**
건물 사이나 지하에서는 오차가 커집니다. 오차 35m를 넘는 신호는 앱이 자동으로 무시합니다.

## 업데이트 (자동입니다)

GitHub에 수정한 파일을 올리기만 하면 됩니다. **버전 숫자를 손으로 올릴 필요가 없습니다.**

앱이 알아서 이렇게 동작합니다:

1. 앱을 켤 때마다 새 버전이 있는지 조용히 확인합니다
2. 있으면 화면 아래에 **"새 버전이 있습니다 — 탭하면 업데이트"** 알림이 뜹니다
3. 탭하면 즉시 적용되고 화면이 새로고침됩니다
4. 무시해도 됩니다. 다음에 앱을 켤 때 다시 안내합니다

**걷는 중에는 알림이 뜨지 않습니다.** 기록이 끊기면 안 되니까요. 걷기를 끝내고 앱을 다시 켤 때 안내합니다.

> 지도 이미지는 예외적으로 캐시를 계속 재사용합니다. 데이터와 배터리를 아끼고, 신호가 약한 곳에서도 지도가 보이게 하기 위해서입니다.

캐시를 통째로 비우고 싶을 때만 `sw.js` 맨 위 숫자를 올리세요.

```js
const CACHE_VERSION = 1;   // → 2로 변경
```

```
├── manifest.json   앱 설치 정보

```
